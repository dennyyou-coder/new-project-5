Recently, a friend shared a Kickstarter product featuring a robot vacuum with me, saying it had some very notable highlights.

The slogan states that Narwal is the world's first robot mop & vacuum featuring innovative self-cleaning technology.

![How Narwal Changed the Robot Vacuum Category image 2](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/02-narwal-and-the-self-cleaning-robot-vacuum-image-002.webp)

![How Narwal Changed the Robot Vacuum Category image 3](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/03-narwal-and-the-self-cleaning-robot-vacuum-image-003.webp)

The core self-cleaning functionality is achieved through 2 water tanks, one for dirty water and one for clean water. Then the robot automatically runs on the base station, with raised slots on the tray that clean the stains where the cloth contacts.

![How Narwal Changed the Robot Vacuum Category image 4](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/04-narwal-and-the-self-cleaning-robot-vacuum-image-004.webp)

![How Narwal Changed the Robot Vacuum Category image 5](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/05-narwal-and-the-self-cleaning-robot-vacuum-image-005.webp)

![How Narwal Changed the Robot Vacuum Category image 6](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/06-narwal-and-the-self-cleaning-robot-vacuum-image-006.webp)

The cleaning effect of a mop that simultaneously automatically rotates is significantly stronger than that of current market-standard floor cleaning robots. It can clean dry red wine stains and markermarks, among others.

![How Narwal Changed the Robot Vacuum Category image 7](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/07-narwal-and-the-self-cleaning-robot-vacuum-image-007.webp)

The motor is simultaneously configured with 18,000 PA, cleaning and suctioning during mopping.

![How Narwal Changed the Robot Vacuum Category image 8](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/08-narwal-and-the-self-cleaning-robot-vacuum-image-008.webp)

Uses a LiDAR navigation solution.

![How Narwal Changed the Robot Vacuum Category image 9](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/09-narwal-and-the-self-cleaning-robot-vacuum-image-009.webp)

Set up virtual walls to prevent the robot from getting stuck in carpets and other areas.

![How Narwal Changed the Robot Vacuum Category image 10](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/10-narwal-and-the-self-cleaning-robot-vacuum-image-010.webp)

Noise as low as 45 dB

![How Narwal Changed the Robot Vacuum Category image 11](/images/articles/narwal-and-the-self-cleaning-robot-vacuum/11-narwal-and-the-self-cleaning-robot-vacuum-image-011.webp)
