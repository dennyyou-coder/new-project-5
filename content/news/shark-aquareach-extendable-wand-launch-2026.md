[Shark](/brands/shark) announced AquaReach on August 18, 2026. The wet-and-dry cleaning system vacuums and mops hard floors, then uses an integrated extendable wand for surfaces such as baseboards, windowsills and cabinet fronts.

The release also described an AquaReach Pro configuration with an automated cleaning and drying system. Package names and model codes need to be checked separately, because retailer names can vary.

WCB's [AquaReach WD551 profile](/products/shark-aquareach-wd551) covers the named base-model code. Features belonging to a Pro or Premium package should not be assumed to apply to WD551. This article records the August product-family announcement.
