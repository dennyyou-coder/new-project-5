# World Clean Biz 索引恢复优先级报告

数据基线：Google Search Console 导出 `worldcleanbiz.com-Coverage-Validation-2026-08-13.xlsx`，报告日期 2026-08-13；GSC 页面报告最近更新日期为 2026-08-07。

## 结论

“已发现 - 尚未编入索引”的 385 个网址不是同一种问题。本轮把它们拆为 117 个 A 级、156 个 B 级和 112 个 C 级，完整逐页清单见 `wcb-gsc-indexation-priority-2026-08-13.csv`。

| 优先级 | 数量 | 处理目标 |
|---|---:|---|
| A | 117 | 核心采购、指南、品牌实体和强搜索意图文章；优先强化入口并抽样请求抓取 |
| B | 156 | 内容有保留价值，但需要主题内链、品牌关系或证据补强 |
| C | 112 | 内容薄、缺少正文内链或缺少外部证据；先改善、合并或观察，不批量催抓 |

页面构成为：309 篇文章、61 个品牌页、7 个指南目录、6 个采购页、1 个专题目录和 1 个展会页。

## 自动分类规则

A/B/C 是执行优先级，不代表 Google 对页面的质量判定，也不等同于删除建议。

- A：采购/指南/比较/OEM/ODM/所有权等明确搜索或商业意图，且正文深度、证据和站内关系信号较完整；核心目录也直接列为 A。
- B：页面本身有效，但主题入口、文章级入站链接、品牌关系或内容证据仍有明显补强空间。
- C：评分不高于 0，常见原因包括正文少于 1,000 词、没有文章级入站链接、没有正文内链或没有外部证据链接。
- 品牌页按关联文章数量分类：有至少 3 篇文章建立关系的为 A，其余为 B；本轮不把品牌页自动归入 C。

文章评分依据已逐行写入 CSV，包括词数、文章内链入站、正文内链、外部证据链接、判定依据与建议动作。

## 本轮技术恢复

1. `/blog/archive?page=N`、`/guides?page=N` 和 `/guides/{type}?page=N` 改为服务端渲染分页，未筛选的合法页码使用自引用 canonical 并允许索引。
2. `category`、`company` 等筛选组合继续使用 `noindex, follow`，防止参数组合扩张索引面。
3. 根站点地图改为 sitemap index，并拆为 Blog、Discovery、Brands、Technical 四组。
4. 分页目录 URL 被显式加入相应 sitemap，减少深层文章只能依赖浏览器执行脚本或长链路发现的风险。

## 发布后执行顺序

### 第 1 周

- 在 GSC 重新提交根站点地图 `https://worldcleanbiz.com/sitemap.xml`。
- 从 A 级中抽样 10–20 个不同模板的网址做“网址检查”，确认实时测试可抓取后再请求编入索引。
- 不要对 385 个网址逐一提交，避免把人工操作当成主要解决方案。

### 第 2–4 周

- 以主题为批次给 B 级文章补 2–3 条真正相关的正文内链；优先从已获展示/点击的页面链接到目标页。
- 给 B 级品牌页补对应文章关系和正文品牌链接。
- 对 C 级先处理最明显的薄内容、零入站链接和零证据链接页面；没有独特搜索价值的旧短文应评估合并，而不是机械扩写。

### 观察指标

- 每周记录“已发现 - 尚未编入索引”总数、已抓取数和已编入索引数。
- 分别跟踪 A/B/C 的抽样 URL，不只看全站总量。
- 以 4–8 周为观察窗口；如果 A 级仍大面积不抓取，再做日志/CDN/Googlebot 访问频率核查，而不是继续批量发布新文章。

## 边界

- 本报告没有把 385 个 URL 的 GSC 状态误判为技术 404：此前抽样页面均返回 200，具备自引用 canonical、允许索引且有单一 H1。
- sitemap 与分页改造提高可发现性，但不能保证 Google 收录。内容独特性、站内重要性和整体抓取需求仍决定最终结果。
- CSV 是 2026-08-13 导出与当前仓库内容的快照；文章、内链或 GSC 状态变化后需要重新分类。
